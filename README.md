# 🧠 MindPilot AI – Real-Time Focus Tracker

## 📌 About the Project

MindPilot AI is a simple computer vision-based application that estimates a user's focus level in real time using their webcam. It was built to explore how computer vision can be used for a practical everyday use case such as studying or working.

The application detects facial landmarks and looks at factors such as eye activity, face direction, and head alignment to generate a focus score. Based on the score, it shows whether the user is **Focused, Partially Focused, or Not Focused** and provides a final focus score and session snapshot when the session ends.

## 🛠️ Technologies Used

- Python
- OpenCV
- MediaPipe
- Streamlit
- Streamlit-WebRTC
- NumPy
